# سليم ERP — نظام إدارة مصنع متكامل

نظام ERP عربي شامل لإدارة المصانع، يغطي دورة العمل الكاملة: **المبيعات، المشتريات، المخازن، الإنتاج، العمال، الخزينة، والتقارير**. يتميز بواجهة عربية كاملة (RTL) ويعمل بمبدأ **Offline-First** مع مزامنة تلقائية بين عدة أجهزة عند توفر الاتصال بالإنترنت.

يدعم النظام تعدد الشركات (Multi-Tenancy) حيث تُعزل بيانات كل شركة تماماً عن الأخرى، مع سجل عمليات (Audit Log) لتتبع جميع التغييرات.

## المزايا الرئيسية

- **المبيعات والمشتريات**: فواتير بيع وشراء مع خصومات وضرائب ورسوم إضافية، مرتجعات مبيعات ومشتريات مع إعادة المخزون تلقائياً، وسدادات للعملاء والموردين.
- **المخازن**: مخازن متعددة الأنواع (خامات، منتجات تامة، عام)، مواد خام ومنتجات بأسعار متعددة (جملة / نصف جملة / قطاعي)، حركات مخزنية (وارد / صادر / تحويل / تسوية)، وحد إعادة الطلب.
- **الإنتاج**: أوامر تشغيل بمراحل ومواد، تتبع الكميات المكتملة، وتسجيل إنتاج العمال بالقطعة مع إضافته للمخزون.
- **العمال والحضور**: عمال بأنظمة أجر مختلفة (شهري / بالإنتاج / بالساعة)، تسجيل حضور وانصراف وساعات إضافية، سلف واستحقاقات، وتقارير مفصلة لكل عامل.
- **الخزينة**: إيداع وسحب وتحويل، مع ربط الحركات بالفواتير والسدادات.
- **المصاريف**: مصاريف مصنفة حسب فئات قابلة للتخصيص.
- **التقارير**: تقارير العملاء والموردين والعمال والمبيعات مع تصدير إلى **Excel وPDF وWord**.
- **النسخ الاحتياطي والاستعادة**: تصدير واستيراد كامل بيانات الشركة.
- **Offline-First**: تخزين محلي عبر IndexedDB ومزامنة متعددة الأجهزة عبر واجهة `/api/sync`.
- **الإعدادات**: بيانات المصنع، الشعار، العملة، بادئة الفواتير، ومعدل الضريبة.

## التقنيات المستخدمة

| المجال | التقنية |
|--------|---------|
| الإطار | Next.js 16 (App Router, Standalone) |
| الواجهة | React 19، Tailwind CSS 4، shadcn/ui، next-intl |
| قاعدة البيانات | PostgreSQL (Neon) مع Prisma 6 |
| العمل دون اتصال | IndexedDB (idb) + Service Worker |
| التصدير | xlsx، jsPDF، html2canvas |
| المصادقة | جلسات مؤمّنة بـ TOKEN_SECRET و bcryptjs |
| النشر | Docker (multi-stage) / Railway (nixpacks) |

## متطلبات التشغيل

- Node.js 22 أو أحدث
- قاعدة بيانات PostgreSQL (يوصى بـ [Neon](https://neon.tech))

## التشغيل محلياً

```bash
# 1. تثبيت الاعتماديات (العلم --legacy-peer-deps مطلوب)
npm install --legacy-peer-deps

# 2. إعداد متغيرات البيئة
cp .env.example .env
# ثم عدّل القيم داخل .env

# 3. إنشاء الجداول في قاعدة البيانات
npx prisma db push

# 4. تشغيل خادم التطوير
npm run dev
```

ثم افتح `http://localhost:3000`.

### أوامر مفيدة

```bash
npm run build        # بناء الإنتاج (يشمل prisma generate)
npm run start        # تشغيل بناء standalone
npm run db:migrate   # إنشاء ترحيلات Prisma
npm run db:reset     # إعادة تعيين قاعدة البيانات
npm run lint         # فحص الكود
```

## متغيرات البيئة

| المتغير | الوصف |
|---------|-------|
| `DATABASE_URL` | رابط اتصال PostgreSQL، مثال: `postgresql://user:password@host:5432/selim_erp?sslmode=require` |
| `TOKEN_SECRET` | مفتاح سري للجلسات، **32 حرفاً عشوائياً على الأقل**. يولَّد بـ: `openssl rand -base64 32` |
| `NODE_ENV` | بيئة التشغيل: `development` أو `production` |

## النشر

### Railway

المشروع جاهز للنشر على Railway عبر `nixpacks.toml`: يثبّت Node 22، يبني وضع standalone، ويشغّل الخادم على المنفذ **8080**. أضف متغيرات البيئة في لوحة Railway فقط.

### Docker

```bash
docker build -t selim-erp .
docker run -p 8080:8080 \
  -e DATABASE_URL="postgresql://..." \
  -e TOKEN_SECRET="..." \
  selim-erp
```

الصورة multi-stage وتستخدم مخرجات Next.js **standalone**، وتنفّذ `prisma db push` تلقائياً عند الإقلاع، وتعمل بمستخدم غير جذري. المنفذ: **8080**.

## ملاحظات أمان

- **عزل الشركات (Multi-Tenancy)**: كل سجل مرتبط بـ `companyId`، ولا يمكن الوصول لبيانات شركة أخرى.
- **المصادقة**: كلمات المرور مشفّرة بـ bcryptjs، والجلسات موقّعة بـ `TOKEN_SECRET` — لا تستخدم القيمة الافتراضية في الإنتاج.
- **Rate Limiting**: حدّ أقصى لمعدل الطلبات على نقاط API الحساسة (خاصة المصادقة).
- **سجل العمليات (Audit Log)**: تُسجَّل جميع العمليات مع المستخدم والوقت والوصف لتتبع التغييرات.
- **التحقق من المدخلات**: عبر Zod في نقاط الـ API.
